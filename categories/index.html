十个抽屉

分类不是标签云，是编辑面对「这东西该放哪」时的第一反应。每栏都有一段自己的说明。

01

AI 工具

AI Tools

从自托管聊天界面到本地推理引擎。这一类项目跑得最快，也最容易在三个月后变成无人维护的遗迹，所以我们只收还在动的，并标出运行它需要多少显存。

进入 AI 工具（3）
Ollama
  • Open WebUI把 Ollama 和任意 OpenAI 兼容模型装进一个自托管聊天台
  • LobeHub（LobeChat）把一堆 AI Agent 编成一个上班的团队

02

开发者工具

Developer Tools

好的开发者工具会消失在工作流里。这一栏收的是那种装完之后你不再想起、但某天换机器时会立刻重新装回来的东西。

进入 开发者工具（3）
uv
  • Hoppscotch打开网页就能发请求的 API 调试台
  • Biome用一套 Rust 工具同时替代 ESLint 和 Prettier

03

效率工具

Productivity

效率工具的价值不在功能多，而在它刚好卡在你每天都会经过的那个路口。这里每个项目都写了真实的上手成本。

进入 效率工具（3）
LocalSend
  • MarkItDown把 PDF、Office 文档统统转成给大模型看的 Markdown
  • Espanso打几个字母，自动展开成一整段文字

04

数据可视化

Data Visualization

同一份数据，换一种呈现方式就换了一种说服力。这一类收代码优先、可复现的可视化与 BI 项目。

进入 数据可视化（3）
PyGWalker
  • Evidence用 SQL 和 Markdown 写会自己更新的数据报告
  • Observable Plot几行代码画出一张能看的图

05

创意与设计

Creative & Design

画布类项目最近几年几乎没有停过。我们挑的是那些在浏览器里就能跑、并且真的能被拿来交付的东西，而不是一次性的 demo。

进入 创意与设计（3）
Excalidraw
  • Screenshot to Code丢一张截图进去，吐出一份能跑的页面代码
  • Penpot能自己部署的开源设计协作平台

06

学习工具

Learning

看教程和真的会，中间隔着一段路。这一栏收的是能让你动手、出错、再重来的学习项目。

进入 学习工具（3）
CS 自学指南
  • Learn Git Branching在浏览器里把 Git 分支玩坏，再学会它
  • TypeScript Exercises十几道题，把 TypeScript 的类型系统练到会

07

开源硬件

Open Hardware

开源硬件项目通常有社区、有文档，也有真实的使用门槛——要买板子、要会接线、要能接受刷坏重来。门槛写在每张卡片上了。

进入 开源硬件（3）
QMK Firmware
  • Flipper Zero一只会读 NFC、红外和 Sub-GHz 的口袋小海豚
  • ESPHome写几行 YAML，把 ESP32 变成自己的智能家居传感器

08

互联网玩具

Internet Toys

这一栏的标准只有一条：它得让人想转发给朋友。有用性不在考核范围内，但可用性必须过关。

进入 互联网玩具（3）
Sherlock
  • IT-Tools一个网页里塞满了开发者会临时用到的小工具
  • DiceBear给一串字符，生成一个永远一样的头像

09

自托管项目

Self-hosted

自托管意味着你同时得到了自由和运维。这里的每个项目都标注了 Docker 跑起来之后，你还需要维护什么。

进入 自托管项目（3）
Immich
  • Karakeep链接、笔记、图片都往里丢，AI 自动打标签
  • Linkwarden收藏网页，同时把网页本身存下来

10

加密与 Web3

Crypto & Web3

这一栏只收开源、可审计、且仍在维护的项目。链上世界风险自负，我们不提供投资建议，也不替任何代币背书。

进入 加密与 Web3（3）
MetaMask
  • FoundryRust 写的以太坊合约开发工具链
  • Rainbow把以太坊钱包做成一只会动的彩虹
