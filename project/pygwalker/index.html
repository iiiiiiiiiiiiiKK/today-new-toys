PyGWalker

把 pandas DataFrame 变成可以拖拽的图表界面

PyGWalker 是 Graphic Walker 的 Python 绑定，作用是在 Jupyter Notebook 里把一个 DataFrame 直接变成可拖拽的交互式分析界面，不用先写绘图代码。README 说它支持可视化、清洗、标注，甚至自然语言查询。对做探索性分析的人来说，它省掉的是「先想清楚画什么图」这一步。

主要功能

  1. DataFrame 直接变界面

    README 说明它把 pandas dataframe 转成可交互的 UI 进行可视化探索。

  2. 拖拽 + 自然语言

    README 写明支持拖拽式可视化、清洗、标注，以及 natural language queries。

  3. 嵌进现有工作流

    README 有 Jupyter Notebook、Streamlit 的独立使用章节。

  4. 图表可导出

    README 包含 Programmatic Export of Charts 一节，说明可在 UI 调好后以代码方式导出图表。

适合谁使用

  • 常在 Jupyter 里做 EDA 的数据分析师
  • 想给非技术同事看一眼数据长什么样的开发者
  • 不想为了一次探索装一整套 BI 的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

零门槛 —— pip 装完在 Notebook 里两行代码就能出界面。

需要：Python 3.9+、Jupyter Notebook 或 Streamlit（可选）

  1. 01

    安装

    pip install pygwalker。

  2. 02

    导入数据

    在 Notebook 里读入 DataFrame。

  3. 03

    起界面

    import pygwalker as pyg 后调用 walk，即可在输出单元里拖拽分析。
