项目概览

Immich 是一个高性能、可自托管的照片与视频管理方案，README 把它放在 Google Photos 的替代位置上：手机自动备份、相册与共享相册、多用户、按时间轴浏览、人脸识别等功能都在。它同时对性能很敏感——这也是它区别于一堆 PHP 相册程序的地方。注意 README 开头那条醒目的 3-2-1 备份警告：自托管意味着备份责任在你。

  1. 移动端自动备份

    README 的功能表把「打开 App 时自动备份」列为移动端支持项，并支持选择要备份的相册。

    README 功能表列出多用户、相册与共享相册、防重复上传等能力。

    仓库 Topics 包含 flutter、svelte、nestjs，对应其移动端与 Web 端技术栈。

适合谁使用

  • 想把家庭照片从云相册搬回自己服务器的人
  • 有 NAS 或家用服务器、愿意维护 Docker 服务的人
  • 需要多人共享相册、又不接受按容量订阅的家庭

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

中等门槛 —— 官方推荐 Docker Compose 部署，跑起来不难，长期维护和备份才是工作量。

需要：一台常开的服务器或 NAS、Docker / Docker Compose、足够的存储空间与备份方案

  1. 01

    先试 Demo

    用 README 给的 demo 账号登录 demo.immich.app，确认功能符合预期。

  2. 02

    按文档部署

    按 immich.app 的安装文档用 Docker Compose 起服务。

  3. 03

    配移动端

    在 App 里填服务器地址，开启自动备份。

成本：软件免费（AGPL-3.0）；服务器与存储自备。
