主要功能

  1. 多端覆盖

    README 说明提供 iOS、Android 应用，以及 Chrome、Brave、Edge、Firefox、Arc 浏览器扩展。

  2. React Native 技术栈

    仓库 Topics 标注 react-native，README 的 Setup 分 iOS 与 Android 两节说明。

  3. 工具链固定版本

    README 的 Prerequisites 要求用 mise 安装固定版本的工具，便于复现构建环境。

  4. 区分内外开发者

    README 分别给出 Internal developers 与 External contributors 的配置步骤，外部贡献者无需私有仓库权限。

适合谁使用

  • 想用一个设计讨喜、开源的以太坊钱包的人
  • 想在手机和浏览器之间同步使用同一钱包的用户
  • 对钱包客户端源码感兴趣的移动端开发者

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

较高门槛 —— 作为用户零门槛；作为开发者要配 iOS/Android 原生环境。

需要：macOS（iOS 开发）、mise、Node.js、yarn、Xcode 或 Android Studio

  1. 01

    普通用户

    从 App Store、Google Play 或浏览器扩展商店安装。

  2. 02

    开发者

    按 README 安装 mise 后执行 mise install，再 corepack enable。

  3. 03

    跑起来

    外部贡献者按 External contributors 一节配置，避免依赖内部私有脚本。

成本：软件免费；链上交互的 gas 费自理。
