项目概览

Linkwarden 是一个可自托管的协作式书签管理器。它和普通书签工具最大的区别写在 README 的动机里：网页会消失（link rot），所以它在收藏时会把页面截图和 PDF 各存一份。除此之外还有阅读、标注、公开分享与多人协作。适合把「资料」当资产而不是当临时标签的人。

主要功能

  1. 收藏即归档

    README 说明会把每个网页保存为截图与 PDF，即使原页面消失也能访问。

  2. 阅读与标注

    README 称其提供阅读与标注体验，把稍后读与网页存档结合起来。

  3. 协作与分享

    README 写明可将链接公开分享，也支持多用户协作。

  4. 官方 Demo

    README 提供 LAUNCH DEMO 入口与 Cloud / 自托管两种使用方式。

适合谁使用

  • 做研究、需要长期保存网页原文的人
  • 团队共享资料链接、希望统一归档的团队
  • 被「404 了才发现文章没了」坑过的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

中等门槛 —— 推荐 Docker 部署，归档功能会占用额外存储。

需要：Docker、PostgreSQL（随官方 compose 提供）、存储空间（截图与 PDF）
