Open WebUI

把 Ollama 和任意 OpenAI 兼容模型装进一个自托管聊天台

Open WebUI 是一个可完全离线运行的自托管 AI 界面，官方 README 把它定位为「a home for AI」：既能接本地 Ollama，也能接 LMStudio、GroqCloud、OpenRouter、vLLM 等任意 OpenAI 兼容 API，并在同一套界面里管理用户、模型与工具。它不是一个模型，而是模型前面的那层工作台——账号、权限、知识库、插件、频道都在这里。

项目概览

主要功能

  1. 一个界面接多家模型

    README 明确写到可同时连接本地 Ollama 与任意 OpenAI 兼容 API（LMStudio、GroqCloud、Mistral、OpenRouter、vLLM 等），在模型之间自由切换。

  2. 细粒度权限与用户组

    管理员可以定义角色、用户组和权限，为每组配置可见的模型与功能，README 称其为 granular RBAC。

  3. 插件与工具服务器

    支持 Filters、Actions、Pipes、Tools、Skills 五类插件，并可通过 MCP、MCPO、OpenAPI 工具服务器接入外部服务。

  4. 不止聊天

    README 还列了 Notes（富文本笔记）、Channels（团队实时频道）、持久记忆、日历与定时自动化，都是围绕对话长出来的周边功能。

适合谁使用

  • 想把本地模型接上一个多人可用界面的开发者
  • 需要给团队分配模型权限、但又不想把对话发到公有云的小团队
  • 已经在跑 Ollama，想要知识库、工具调用和频道功能的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

中等门槛 —— 会敲一条 docker run 就能跑起来，但要用好需要自己准备模型或 API Key。

需要：Docker 或 Python 3.11+、Ollama 或任意 OpenAI 兼容 API、约 2GB 内存起步（不含模型）

  1. 01

    起容器

    README 给出的命令：docker run -d -p 3000:8080 --add-host=host.docker.internal:host-gateway -v open-webui:/app/backend/data --name open-webui ghcr.io/open-webui/open-webui:main

  2. 02

    打开 3000 端口

    首次访问会要求注册管理员账号，第一个注册的用户即为管理员。

  3. 03

    接模型

    本机已装 Ollama 时容器会自动发现；否则在设置里填 OpenAI 兼容的 Base URL 和 Key。

成本：软件免费；模型费用取决于你接的是本地模型还是云端 API。
