项目概览

Evidence 是一个「BI as code」工具：报告不是拖拽出来的，而是用 SQL 查询加 Markdown 排版写出来的，构建后生成可托管的静态站点。README 把它定位为拖拽式 BI 的开源替代。对已经习惯用 Git 管内容的团队，这意味着图表能进 code review，数据口径也能留痕。

主要功能

  1. SQL + Markdown 写报告

    README 首段即写明：用 SQL 与 markdown 在代码里创建报告，是拖拽式 BI 工具的开源替代。

  2. 静态输出

    README 说明可发布到 Evidence Studio，也可把生成的静态站点自托管在自己的基础设施上。

  3. 对数据栈友好

    仓库 Topics 列出 dbt、duckdb、snowflake 等，说明其定位是接现有数据仓库而非替代它。

  4. Agent 友好

    README 开头称其为 agent-ready 的报告工具，并提及可用 Claude Code / Cursor 等工具开发。

适合谁使用

  • 想让数据报告进版本控制的分析团队
  • 已经用 dbt / DuckDB 管数据、缺一个展示层的人
  • 需要把报表以静态站点交付、不想维护 BI 服务器的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

中等门槛 —— 要有一条能跑 SQL 的数据源，模板项目本身一条命令即可初始化。

需要：Node.js、一个数据库或数据文件（如 DuckDB）

  1. 01

    初始化

    按 README 的 Create a Project 步骤生成项目骨架。

  2. 02

    连数据

    在配置里指向你的数据库或本地数据文件。

  3. 03

    写页面

    在 markdown 页面里嵌 SQL 查询与图表组件，本地预览后构建。

成本：开源版免费；托管版 Evidence Studio 另行计费。
