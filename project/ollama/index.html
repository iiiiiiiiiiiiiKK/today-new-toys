项目概览

Ollama 把「下载模型、跑起来、对外提供 API」压缩成一条命令。README 现在的定位是本地与云端都能用：既可以在自己的 Mac / Windows / Linux 上离线跑，也可以连官方云模型。它真正的价值不是模型本身，而是把推理服务做成了一个开发者不用关心的黑盒——装好之后你面对的是一个 REST API 和命令行。

主要功能

  1. 一条命令拉模型

    README 的 Get started 章节演示了直接运行模型并进入对话，模型库见 ollama.com/library。

  2. REST API

    README 明确提供用于运行和管理模型的 REST API，并有独立的 API 文档。

  3. 官方多语言 SDK

    README 列出 ollama-python 与 ollama-js 两个官方库。

  4. 接入现有编码工具

    README 说明可以把 Ollama 接到 Claude Code、Codex、Copilot CLI、OpenCode 等工具上作为后端。

适合谁使用

  • 想在本机跑模型、又不想折腾 CUDA 和推理框架的人
  • 需要给本地应用接一个 OpenAI 风格接口的后端开发者
  • 对数据出境敏感、希望完全离线运行的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

零门槛 —— 下载安装包或跑一条 docker 命令即可，不需要 Python 环境。

需要：8GB 内存起步（7B 级模型建议 16GB）、可选：NVIDIA / AMD 显卡加速

  1. 01

    安装

    从 ollama.com 下载 macOS / Windows / Linux 版本，或使用官方 Docker 镜像 ollama/ollama。

  2. 02

    跑一个模型

    按 README 的 Get started 选择模型并运行，首次会自动下载权重。

  3. 03

    接进自己的程序

    调用本地 REST API，或安装 ollama-python / ollama-js。

成本：软件免费；本地运行只花电费，云端模型按官方定价。
