主要功能

  1. 局域网直传

    README 首段写明：在同一本地网络内安全地分享文件与消息，无需互联网连接。

  2. 跨平台

    README 的 Download 表格分别列出 Android、iOS、Windows、macOS、Linux 的安装方式。

  3. 不依赖中心服务器

    README 的 How It Works 章节描述设备间直接通信的机制。

  4. 附带 CLI

    README 有独立的 Command Line Interface 章节。

适合谁使用

  • 家里同时有 Windows、macOS 和安卓设备的人
  • 经常要在会议室把文件发给同事、又不想走微信的人
  • 对「文件必须过一遍云」这件事不放心的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

零门槛 —— 两端各装一个 App，在同一 Wi-Fi 下即可。

需要：两台在同一局域网的设备、允许应用访问本地网络（部分系统需授权）

  1. 01

    安装

    按 README 的 Download 表选择对应平台的安装包或应用商店。

  2. 02

    连同一网络

    确保设备在同一个 Wi-Fi 或热点下。

  3. 03

    互传

    打开应用，选择设备后发送文件。

成本：完全免费，无广告，无账号。
