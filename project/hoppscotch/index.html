项目概览

Hoppscotch 是一个开源的 API 开发生态，README 直接把自己定位成 Postman / Insomnia 的开源替代品，覆盖 Web、桌面与 CLI 三种形态。它最实用的一点是轻：浏览器打开就能发第一个请求，不用装客户端，也不用登录。需要离线或团队协作时，再考虑自托管。

主要功能

  1. 覆盖多种协议

    仓库 Topics 与 README 功能列表包含 REST、GraphQL、WebSocket、SSE 等请求类型。

  2. 完整 HTTP 方法

    README 逐条列出 GET / POST / PUT / PATCH / DELETE / HEAD / OPTIONS 等方法，并支持自定义方法。

  3. PWA，可离线

    仓库 Topics 标注 pwa，README 强调轻量与快速；Web 版可安装为桌面应用。

  4. 三种形态

    README 首段说明提供 Web、桌面与 CLI 版本，并支持自托管。

适合谁使用

  • 偶尔要调接口、不想为这个装一个 Electron 客户端的人
  • 需要 WebSocket / GraphQL / SSE 一起调的开发者
  • 想在内网自托管一套 API 工具链的团队

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

零门槛 —— 直接打开 hoppscotch.io 就能用，不需要账号。

需要：现代浏览器、可选：Docker（自托管）

  1. 01

    直接用

    打开 hoppscotch.io，新建请求，填 URL 发送。

  2. 02

    想离线

    用浏览器的「安装应用」把 Web 版装成 PWA，或下载桌面客户端。

  3. 03

    团队自托管

    按文档用 Docker 部署，并配置所用的后端服务。

成本：开源版免费；官方云版有付费团队功能。
