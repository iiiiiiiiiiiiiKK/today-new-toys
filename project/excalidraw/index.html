Excalidraw

画出来像手绘的白板，协作还是端到端加密的

项目概览

Excalidraw 是一个开源的虚拟白板，最出名的是那种手绘质感的线条。README 说明它以 npm 包形式发布编辑器，同时 excalidraw.com 上的官方应用本身就支持实时协作与端到端加密。它适合画架构草图、流程和线框图——不是精细设计工具，而是「先把想法画出来给人看」的那一层。

主要功能

  1. 手绘风格画布

    README 的 Features 列出无限画布、hand-drawn like style、矩形/圆形/菱形/箭头/自由绘制/橡皮等工具。

  2. 实时协作 + 端到端加密

    README 说明 excalidraw.com 应用支持 PWA 离线使用、实时协作，并强调 end-to-end encrypted。

  3. 开放文件格式

    README 写明可导出为 .excalidraw JSON，也可导出 PNG、SVG 或复制到剪贴板。

  4. 可作为组件嵌入

    README 首段说明编辑器以 npm 包形式提供，并列出多项集成案例。

适合谁使用

  • 需要快速画架构图、流程图给同事看的人
  • 想要一块不登录也能用的在线白板的人
  • 在意协作内容加密、不想上传设计稿的团队

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

零门槛 —— 打开网页就能画。

需要：现代浏览器

  1. 01

    直接画

    打开 excalidraw.com，选形状工具开始画。

  2. 02

    协作

    点分享生成协作链接，对方打开即可同屏编辑。

  3. 03

    导出

    导出 PNG / SVG，或保存 .excalidraw 源文件以便以后再改。

成本：开源版免费；官方 Excalidraw+ 为付费托管服务。
