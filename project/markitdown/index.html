项目概览

MarkItDown 是微软开源的轻量 Python 工具，把 PDF、Word、Excel、PPT、图片、音频等格式转成 Markdown，目标用户是喂给 LLM 的文本流水线，而不是追求排版还原的人类读者。README 一开始就写了两个关键限制：它保留结构（标题、列表、表格、链接）但输出不保证好看；并且它会以当前进程权限访问资源，处理不可信文件前必须自己做好隔离。

主要功能

  1. 多格式输入

    README 明确列出支持 PDF、PowerPoint、Word、Excel、图片（EXIF 与 OCR）、音频（EXIF）等来源。

  2. 保留文档结构

    README 说明转换时尽量保留标题、列表、表格、链接等 Markdown 结构，这是它相对通用文本抽取工具的区别。

  3. 命令行与 Python API 两用

    README 的 Usage / Command-Line 章节给出 CLI 与库调用两种用法，示例为 markitdown path-to-file.pdf -o document.md。

  4. 按需安装可选依赖

    README 演示了 pip install 'markitdown[pdf,docx,pptx]' 这种只装需要格式的写法。

适合谁使用

  • 要批量把一堆文档塞进 RAG 知识库的人
  • 需要把会议材料、报表快速转成可检索文本的团队
  • 在写文档处理脚本、想省掉解析库选型的开发者

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

低门槛 —— pip 装完即可用，但需要 Python 3.10–3.14。

需要：Python 3.10–3.14、按需的格式解析依赖

  1. 01

    安装

    pip install 'markitdown[all]'，或只装用得到的格式，如 [pdf,docx,pptx]。

  2. 02

    转换

    markitdown 输入文件 -o 输出.md，或在 Python 里调用 convert 系列函数。

  3. 03

    接入流水线

    把输出接到你的切分、嵌入与检索流程里。

成本：免费开源（MIT），无外部服务依赖。
