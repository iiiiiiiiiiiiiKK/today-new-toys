项目概览

Screenshot to Code 把截图、设计稿甚至屏幕录制转成 HTML/Tailwind、React、Vue 等前端代码，背后调用的是各家视觉模型。README 明确写了：本地运行需要 API Key 和后端/前端两套服务，最省事的方式是用官方托管版。它适合做原型的第一版，不适合直接当成生产代码交付。

主要功能

  1. 多技术栈输出

    README 列出支持 HTML + Tailwind、HTML + CSS、React + Tailwind、Vue + Tailwind、Bootstrap、Ionic + Tailwind。

  2. 截图之外的输入

    README 说明除了截图与 Figma 设计稿，还支持把网页操作的屏幕录制转成可运行原型。

  3. 可切换多家模型

    README 的 Default AI models 一节列出 Gemini、GPT、Claude 等可选模型，并支持 Replicate 的图像生成模型。

  4. 本地与托管两种用法

    README 的 Getting Started 明确区分「本地运行（需 API Key）」与「直接用托管版」。

适合谁使用

  • 手里只有设计稿、想快速起一个可点原型的前端
  • 在评估视觉模型写前端能力的技术负责人
  • 需要从竞品截图快速复刻布局的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

中等门槛 —— 本地跑要同时起前后端、装 Playwright 的 Chromium，还要自备模型 Key。

需要：Python 后端 + Node 前端、至少一个视觉模型 API Key、Playwright Chromium（截图预览用）

  1. 01

    先试托管版

    打开 screenshottocode.com 上传截图，确认效果符合预期。

  2. 02

    本地部署

    按 README 的 Getting Started 分别启动后端与前端。

  3. 03

    配 Key

    在环境变量里填所选模型厂商的 Key，按 README 安装 Chromium 预览依赖。

成本：代码 MIT；模型调用按各家 API 计费。
