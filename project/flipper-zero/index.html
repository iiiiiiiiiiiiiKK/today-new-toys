适合谁使用

  • 对射频、NFC 感兴趣、想动手做实验的硬件爱好者
  • 已经买了设备、想自己改固件或写应用的人
  • 做安全研究、需要一台便携实验设备的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

较高门槛 —— 设备需单独购买；自编译固件要装工具链并接受刷坏的风险。

需要：Flipper Zero 设备、ARM 工具链（自编译固件）、USB 线或调试器

  1. 01

    先看用户文档

    README 建议从用户文档入手，确认设备能力与本地法律限制。

  2. 02

    更新固件

    按 README 指向的固件更新页，用官方工具升级。

  3. 03

    自编译（可选）

    按 README 的 Requirements 安装工具链，克隆源码后构建并通过 USB 刷入。

成本：固件免费；硬件为付费产品。
