项目概览

Learn Git Branching 是一个交互式 Git 教学工具：左边敲命令，右边的提交树实时变化。README 说它的核心目的就是「用可视化理解 Git」——命令行里最难建立直觉的部分，在这里变成了一棵能看见的树。除了关卡，它还有一个沙盒模式，可以随便折腾。

主要功能

  1. 提交树实时可视化

    README 说明输入命令后，旁边的 commit tree 会动态更新以反映命令效果。

  2. 关卡式教程

    README 写明它由一系列教育性教程与挑战组成，难度循序渐进。

  3. 沙盒模式

    README 有独立的 Sandbox Mode 章节，默认会先给一个基础仓库让你随便操作。

  4. 支持分享与自建关卡

    README 列出 Sharing permalinks 与 Level Builder 章节。

适合谁使用

  • 刚学 Git、对 rebase 和 merge 的区别没概念的人
  • 想给团队做 Git 培训、需要一个能动手的演示环境的人
  • 准备面试、想复习分支操作的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

零门槛 —— 打开网页就能开始，不需要装 Git。

需要：现代浏览器

  1. 01

    打开

    访问 learngitbranching.js.org，中文界面可直接切换。

  2. 02

    从基础关开始

    按顺序做关卡；卡住时可以看提示。

  3. 03

    去沙盒乱来

    在 Sandbox 里自由试验 reset、rebase、cherry-pick。

成本：免费开源（MIT）。
