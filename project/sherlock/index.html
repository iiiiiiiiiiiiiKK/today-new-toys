Sherlock

给一个用户名，扫遍 400 多个社交平台

Sherlock 是一个用 Python 写的命令行工具，输入一个或多个用户名，它会在 400 多个社交网络上检查对应账号是否存在，并把结果写入文件。它属于 OSINT（公开信息搜集）工具，README 的定位也很直白：给安全研究、取证和红队工作用。用它之前请先想清楚——查别人的账号分布这件事，在很多场景下是有边界的。

项目概览

Sherlock 是一个用 Python 写的命令行工具，输入一个或多个用户名，它会在 400 多个社交网络上检查对应账号是否存在，并把结果写入文件。它属于 OSINT（公开信息搜集）工具，README 的定位也很直白：给安全研究、取证和红队工作用。用它之前请先想清楚——查别人的账号分布这件事，在很多场景下是有边界的。

主要功能

  1. 覆盖 400+ 站点

    README 首句写明可在 400 多个社交网络上按用户名查找账号。

  2. 支持批量与导出

    README 的 General usage 演示一次查多个用户名，并说明结果会按用户名写入独立文件；命令行帮助里还提供 --csv、--xlsx 等输出选项。

  3. 多种安装方式

    README 列出 pipx、pip/uv、Docker 以及各发行版包管理器等多种安装路径。

  4. 社区维护的站点列表

    README 用 Contributors 章节致谢站点数据的贡献者，说明站点清单是持续维护的。

适合谁使用

  • 做公开信息搜集（OSINT）的安全研究者
  • 想检查自己用户名在哪些平台被注册的人
  • 需要批量核验账号存在性的取证场景

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

低门槛 —— pipx 一条命令装好即可，无需配置。

需要：Python 3.9+ 或 Docker、可访问目标站点的网络环境

  1. 01

    安装

    pipx install sherlock-project（或用 README 列出的其他方式）。

  2. 02

    查一个用户名

    sherlock user123，结果会在当前目录生成同名文本文件。

  3. 03

    批量与导出

    sherlock user1 user2 user3，配合 --csv 或 --xlsx 输出结构化结果。

成本：免费开源（MIT）。
