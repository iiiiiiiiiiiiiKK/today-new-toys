项目概览

Foundry 是一套用 Rust 写的以太坊应用开发工具，README 把它拆成几件兵器：Forge 负责编译、测试、模糊测试与部署合约；Cast 负责从命令行读写链上数据；Anvil 提供一个本地节点；Chisel 是一个 Solidity REPL。对习惯命令行和 CI 的合约团队，它比图形化 IDE 更容易纳入自动化。

主要功能

  1. Forge：编译到部署

    README 说明 Forge 负责构建、测试、模糊测试、调试与部署 Solidity 合约。

  2. Cast：链上交互

    README 描述 Cast 是操作 EVM 合约、发送交易与读取链上数据的命令行工具。

  3. Anvil：本地节点

    README 列出 Anvil 作为本地以太坊节点，支持分叉。

  4. Chisel：Solidity REPL

    README 说明 Chisel 是用于快速试验与调试的 Solidity REPL。

适合谁使用

  • 写 Solidity、希望测试和部署都在命令行完成的合约开发者
  • 需要把合约测试接进 CI 的团队
  • 想做模糊测试（fuzzing）的审计人员

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

低门槛 —— 一条 curl 安装脚本即可，但需要懂 Solidity 才有东西可编译。

需要：macOS / Linux（Windows 建议 WSL）、基础 Solidity 知识

  1. 01

    安装

    运行官网给出的 curl -L https://foundry.paradigm.xyz | bash，再执行 foundryup。

  2. 02

    建项目

    forge init 生成标准目录结构。

  3. 03

    写测试

    在 test 目录用 Solidity 写测试，forge test 运行；需要本地链时启动 anvil。

成本：免费开源（Apache-2.0 / MIT 双许可，以仓库为准）。
