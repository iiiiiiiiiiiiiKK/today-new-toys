项目概览

Karakeep（原名 Hoarder）是一个可自托管的「书签一切」应用：网页链接、随手笔记、图片、PDF 都能存，抓取标题描述和封面后，用 LLM 自动打标签并做全文与语义搜索。README 的自述是写给「数据囤积者」的。它和稍后读工具的区别在于：它真的把内容存下来了，而不是只存一个链接。

主要功能

  1. 书签一切

    README 的 Features 首条写明可收藏链接、记简单笔记、存图片与 PDF。

  2. 自动抓取元信息

    README 说明会自动抓取链接的标题、描述与图片。

  3. AI 标签与语义搜索

    README 列出基于 LLM 的自动打标签与摘要（支持本地 Ollama 模型），以及全文与语义搜索。

  4. 防链接失效

    README 提到用 monolith 做整页归档，以及用 yt-dlp 自动归档视频。

适合谁使用

  • 收藏夹里堆了几百条链接、从来没打开过的人
  • 想要一个自己的「第二大脑」、但不想把数据交给 SaaS 的人
  • 需要给研究资料自动打标签的研究者

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

中等门槛 —— Docker 部署简单，但想用 AI 标签得额外配一个模型（本地或云端）。

需要：Docker、可选：OpenAI Key 或本地 Ollama、浏览器扩展（可选）

  1. 01

    先试 Demo

    用 README 提供的 try.karakeep.app 演示账号体验（只读）。

  2. 02

    部署

    按官方文档的 Docker 步骤起服务。

  3. 03

    接模型

    如果要自动标签，在设置里配置 LLM；可用 Ollama 本地模型。

成本：软件免费（AGPL-3.0）；AI 功能按所选模型计费。
