QMK Firmware

自己定义每一颗键位的键盘固件

QMK 是一个基于 tmk_keyboard 的开源键盘固件，支持 Atmel AVR 与 ARM 控制器，README 点名的官方支持产品线包括 OLKB、ErgoDox EZ、Clueboard 等。它的意义在于把键盘行为从厂商手里拿回来：层、宏、组合键、RGB 都能改写，代价是你得先弄清自己的板子是哪一颗芯片。

主要功能

  1. 广泛的主控支持

    README 说明固件基于 tmk_keyboard，面向 Atmel AVR 与 ARM 控制器。

  2. 官方与社区键盘库

    README 列出 Planck、Preonic、ErgoDox EZ、Clueboard、Cluepad、Atreus 等官方支持产品，并说明社区支持大量其他键盘。

  3. 在线配置器

    README 指向 qmk.fm 与文档站，官方提供 config.qmk.fm 在线编译入口。

  4. 完整文档

    README 说明文档托管在 docs.qmk.fm，并可离线预览。

适合谁使用

  • 买了客制化键盘、想改键位和层的人
  • 在做自己的 PCB、需要一套成熟固件的硬件开发者
  • 想把机械键盘改成符合自己肌肉记忆布局的重度打字者

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

较高门槛 —— 要装工具链、认主控、会刷机；刷坏需要能救砖。

需要：可刷写的键盘或自制 PCB、QMK CLI / 编译工具链、对应主控的刷机方式（DFU 等）

  1. 01

    确认板子

    在 QMK 文档的键盘列表里找到自己的型号，确认主控与刷机方式。

  2. 02

    在线试配置

    用 config.qmk.fm 先编译一版固件，验证键位思路。

  3. 03

    本地构建

    按 README 克隆仓库并安装依赖，用 qmk compile 生成固件后刷入。

成本：固件免费；硬件自备。
