项目概览

Penpot 是一个开源的在线设计平台，面向需要规模化协作的产品团队。README 的卖点是「完全掌控自己的设计基础设施」：可自托管、基于 SVG/CSS/HTML/JSON 等开放标准、原生支持 Design Tokens，并提供开发者可直接读取的 Inspect 模式。它不是 Figma 的克隆，而是把「设计即代码」这条路线做得更彻底。

主要功能

  1. 浏览器内实时协作

    README 写明无论用浏览器还是自建服务器，都支持实时协作。

  2. 开放标准文件

    README 强调基于 SVG、CSS、HTML、JSON 等开放标准，设计结果对开发者可读。

  3. 原生 Design Tokens

    README 称其提供 best-in-class 的 Design Tokens，作为设计与代码之间的单一事实来源。

  4. Inspect 模式与插件

    README 有独立的 Inspect mode 与 Plugin system 章节，方便开发者取用样式与扩展能力。

适合谁使用

  • 因合规要求不能把设计稿放公有云的产品团队
  • 希望设计和前端共用一套 token 的团队
  • 想摆脱按席位计费的设计协作工具的组织

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

较高门槛 —— 用官方云版零门槛；自托管要自己维护一套多服务架构。

需要：现代浏览器（云版）、Docker / Kubernetes（自托管）

  1. 01

    先用云版

    在 penpot.app 注册即可开始设计，验证工作流是否合适。

  2. 02

    准备自托管

    按 README 指向的自托管文档，用 Docker 或 Kubernetes 部署。

  3. 03

    接设计系统

    在项目里配置 Design Tokens 与组件库，前端通过 Inspect 取样式。

成本：开源版免费；企业版为付费方案。
