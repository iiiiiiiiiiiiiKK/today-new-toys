ESPHome

写几行 YAML，把 ESP32 变成自己的智能家居传感器

ESPHome 让你用配置文件而不是代码来定义 ESP32 / ESP8266 / BK72xx / RP2040 的行为：读哪个引脚、上报什么数值、接到哪个家居平台。官网的说法是「商店里买不到想要的设备，就自己做一个」。它和 Home Assistant 配合最顺，但也能通过 MQTT 接入其他系统。

主要功能

  1. 配置代替编程

    官网首页明确写到：告诉 ESPHome 要做什么，其余由它处理，无需写代码。

  2. 支持多种芯片

    仓库描述列出 ESP32、ESP8266、BK72xx、RP2040 四类平台。

  3. 接入家居系统

    README 与仓库 Topics 标明与 Home Assistant、MQTT 集成。

  4. 组件化

    官网导航有 Components 一栏，按传感器/屏幕/开关等分类提供现成组件。

适合谁使用

  • 想自己做温湿度、人体感应节点接进 Home Assistant 的人
  • 会一点 YAML、但不想写 C++ 的 DIY 爱好者
  • 需要批量部署同款自制传感器的小型工作室

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

中等门槛 —— 需要一块开发板和一次 USB 刷机，之后可以 OTA 更新。

需要：ESP32 / ESP8266 等开发板、USB 数据线（首次刷机）、可选：Home Assistant

  1. 01

    装 ESPHome

    用 Home Assistant 的 ESPHome 插件，或 pip 安装命令行工具。

  2. 02

    写配置

    新建 YAML，声明板型、Wi-Fi、要用的传感器组件。

  3. 03

    首次刷机

    USB 连接开发板刷入；之后可通过网络 OTA 更新。

成本：软件免费；开发板与传感器按硬件成本。
