Espanso

打几个字母，自动展开成一整段文字

Espanso 是一个用 Rust 写的跨平台文本扩展器（text expander）：你输入一个触发词，它替换成一段预设内容——常用回复、代码片段、日期、甚至执行脚本后的结果。README 强调隐私优先、100% 本地运行、不追踪用户。对每天要重复输入同样几句话的人来说，这类工具省下的时间比想象中多。

主要功能

  1. 跨平台文本扩展

    README 的 Key Features 首条即写明支持 Windows、macOS、Linux，并可在几乎任何程序中工作。

  2. 本地优先，不追踪

    README 明确标注 privacy-first、100% local、no tracking。

  3. 不只是纯文本

    README 列出支持图片、表情、日期展开、自定义脚本、Shell 命令、表单与正则触发。

  4. 配置即文件

    README 说明采用文件化配置，并内置 espanso hub 包管理器。

适合谁使用

  • 每天要重复输入客服话术、邮件模板的人
  • 想要系统级代码片段、又不想被某个编辑器绑死的人
  • 愿意花半小时配置、换长期效率的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

低门槛 —— 装完还要写几行 YAML，第一次配完就回不去了。

需要：Windows / macOS / Linux、一个文本编辑器（改配置文件）

  1. 01

    安装

    按官网说明下载对应平台安装包。

  2. 02

    写第一条规则

    在 match 目录下新建 YAML，定义 trigger 与 replace。

  3. 03

    重载配置

    保存后 espanso 会自动热重载，直接在任意应用里输入触发词测试。

成本：免费开源（GPL-3.0）。
