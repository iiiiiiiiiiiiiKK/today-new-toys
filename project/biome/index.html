项目概览

Biome 是一个面向 Web 项目的工具链，把格式化和静态检查收进同一个二进制文件。README 的定位很清楚：为前端项目提供维护所需的那些基础能力，CLI 和 LSP 两种形态都有。对饱受 ESLint 插件地狱折磨的项目来说，它的吸引力不在功能更多，而在配置更少、跑得更快。

主要功能

  1. 格式化 + 检查二合一

    README 的 Usage 章节分别给出 biome format、biome lint 以及一次跑完两者的 biome check 命令。

  2. 面向 CI 的检查模式

    README 专门演示了在 CI 环境中对所有文件做格式与规则检查的用法。

  3. CLI 与编辑器双形态

    README 首段即说明提供 CLI 与 LSP；仓库同时发布 VS Code 与 Open VSX 扩展。

  4. 覆盖 JS/TS 生态

    仓库 Topics 列出 javascript、typescript、jsx、css、json，README 支持列表与此一致。

适合谁使用

  • 受够 ESLint + Prettier 两套配置和插件冲突的前端团队
  • 想要一个快的 formatter 接入 CI 的人
  • 新项目起步，不想从零拼装 lint 规则的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

零门槛 —— npm 装一个包，或装编辑器扩展即可，不需要改构建流程。

需要：Node.js 18+ 或编辑器扩展、现有项目（可选）

  1. 01

    安装

    按 README 的 Installation 章节，用包管理器安装 @biomejs/biome。

  2. 02

    初始化配置

    运行 biome init 生成 biome.json。

  3. 03

    跑一次检查

    biome check . 同时做格式与规则检查，按提示加 --write 应用安全修复。

成本：免费开源。
