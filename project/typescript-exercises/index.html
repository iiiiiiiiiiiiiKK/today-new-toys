项目概览

TypeScript Exercises 是一组循序渐进的交互式练习，README 说目标是让人「玩遍 TypeScript 的各种特性」并建立整体认识。它覆盖基础类型、类型收窄、联合类型、泛型、模块扩充、高级类型映射等主题，并且明确要求：尽量不用 any。适合已经会写 TS、但一遇到复杂类型就卡住的人。

内容依据

依据仓库 README.md（约 800 字，2026-10-24 抓取）的 Things to cover / Rules and principles / Contributing 章节整理。

主要功能

  1. 按主题递进

    README 的 Things to cover 列出 Basic typing、Refining types、Union types、Generics、Module augmentation、Advanced type mapping 等主题。

  2. 浏览器内做题

    README 给出在线地址 typescript-exercises.github.io，直接在网页里写代码并验证。

  3. 明确禁止 any

    README 的 Rules and principles 第一条就是 Avoid using any type at all costs。

  4. 难度递增

    README 说明难度会在练习之间快速上升。

适合谁使用

  • 写得出业务代码、但读不懂复杂类型声明的前端
  • 准备面试、想系统过一遍 TS 类型特性的人
  • 团队新人培训，需要一套能自动校验的练习

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

零门槛 —— 打开网页即可做题。

需要：浏览器、基础 TypeScript 语法

  1. 01

    打开练习

    访问 typescript-exercises.github.io 从第一题开始。

  2. 02

    做题

    按题目要求补全类型，页面会给出校验结果。

  3. 03

    本地跑（可选）

    克隆仓库后按 README 用 yarn start 起本地开发服务器。

成本：免费开源（MIT）。
