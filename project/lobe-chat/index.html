项目概览

LobeHub 的前身是 LobeChat，一个开源的 AI 聊天界面；现在仓库的自我描述已经改成「Chief Agent Operator」——把多个 Agent 当成可招聘、可排班、可汇报的成员来组织。README 里保留了一条很重要的提醒：项目仍在活跃开发中。想要一个漂亮的多模型聊天前端，它依然称职；想要一个稳定的企业级 Agent 调度平台，得先接受它会变。

主要功能

  1. 多模型统一入口

    README 的 Features 与 Environment Variable 章节列出 OpenAI、Claude、Gemini、DeepSeek、GLM 等模型的接入配置，可在同一界面切换。

  2. Agent 作为工作单元

    README 用 Operator / Create / Collaborate / Evolve 四节描述产品方向：Agent 可以被创建、排班、协作并汇报，而不只是单轮对话。

  3. 插件与 MCP

    README 有独立的 Plugins 与 MCP 章节，支持通过插件扩展能力、接入 MCP 工具。

  4. 一键部署

    README 给出 Vercel、Zeabur、Sealos、阿里云与 Docker 五种部署路径，并提供环境变量清单。

适合谁使用

  • 需要一个同时接 GPT、Claude、Gemini、DeepSeek 的聊天前端的人
  • 想试 Agent 编排，但不想一上来就买商业平台的小团队
  • 喜欢现代前端设计、会在意界面手感的人

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

低门槛 —— 可以直接用官方托管版；自托管需要准备模型 API Key 和数据库。

需要：Node.js 20+（本地开发）或 Docker、至少一个模型提供商的 API Key、自托管需 PostgreSQL

  1. 01

    先用托管版试

    打开 lobehub.com 注册即可体验，不必先部署。

  2. 02

    自托管

    README 的 Self Hosting 章节给出 Docker 与 Vercel 两种方式，按其中一种准备环境变量。

  3. 03

    填 Key

    在 Environment Variable 章节按所选模型厂商填对应变量，不要写进前端代码。

成本：软件免费；模型调用按各家 API 计费。
