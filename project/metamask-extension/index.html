  • 想读钱包扩展实现、学习 dApp 注入机制的开发者
  • 准备给 MetaMask 提交 PR 的贡献者

使用方式

较高门槛 —— 普通用户装扩展即可；改源码要 Node 环境、依赖安装和较长的首次构建。

需要：Node.js 与 yarn、Chrome / Firefox（加载未打包扩展）、足够的磁盘与内存（构建较重）

  1. 01

    普通用户

    从 metamask.io 跳转到对应浏览器商店安装。

  2. 02

    开发者

    按 README 克隆仓库、安装依赖并构建，然后在浏览器里加载开发版扩展。

  3. 03

    跑测试

    按 README 的 Testing 章节运行单元测试与 E2E 测试。

成本：软件免费；链上操作 gas 自理。
