主要功能

  1. 工具集合

    README 首句即定义为一组面向开发者与 IT 人员的实用在线工具，仓库 Topics 列出 converter、developer-tools、productivity 等类别。

  2. 可自托管

    README 的 Self host 章节给出 Docker Hub 与 GitHub Packages 两种镜像，以及 Cloudron、Tipi、Unraid 等部署方式。

  3. 可扩展

    README 有 Create a new tool 章节，说明如何新增一个工具。

  4. 前端技术栈清晰

    README 的开发章节基于 Vue 3 + TypeScript + Vite，并提供单元测试与 ESLint 配置说明。

适合谁使用

  • 经常需要临时做一次编码转换、哈希、时间戳计算的开发者
  • 不想把内部数据贴到随机在线工具网站的团队
  • 想给团队内网放一个工具箱的运维

反过来：如果你只是想要一个现成的成品、不想读文档或配置环境，这个项目可能不适合你。

使用方式

零门槛 —— 打开网站就能用；自托管也只需要一条 docker 命令。

需要：现代浏览器、可选：Docker

  1. 01

    直接用

    打开 it-tools.tech，左侧选工具。

  2. 02

    自托管

    docker run -d --name it-tools --restart unless-stopped -p 8080:80 corentinth/it-tools:latest

  3. 03

    内网分发

    把容器放到内网，团队成员通过内网地址访问，避免数据外传。

成本：免费开源（GPL-3.0）。
